# @agent-plan/mcp

MCP server for Agent Plan.

Exposes `planner-*` tools over stdio for hosts such as Claude Code and Codex.

Use `planner-version` (or `/planner version` in the Claude plugin) to report the `@agent-plan/mcp` and `@agent-plan/core` versions actually loaded by the server process. The tool works without an initialized `.planner/` workspace.

See the repository root README for full documentation:
https://github.com/ovidius72/agent-planner#readme
