# agent-plan

CLI package for Agent Plan.

## What it provides
- `agent-plan --version` / `agent-plan -v`
- `agent-plan init` (`--description`, `--goal`, `--json`)
- `agent-plan serve` (`--root`, `--port`, `--host`, `--json`)
- `agent-plan mcp`
- `agent-plan export`
- `agent-plan setup claude-code`
- `agent-plan setup codex`
- `agent-plan setup opencode`
- `agent-plan guard pre-tool-use`

See the repository root README for full documentation:
https://github.com/ovidius72/agent-planner#readme
